پروژه ساده Hello World با Node.js و Express

پیش‌نیاز:
- نصب Node.js

مراحل اجرا:
1. فایل‌ها را از حالت فشرده خارج کنید.
2. ترمینال را در پوشه پروژه باز کنید.
3. دستور زیر را اجرا کنید:
   npm install
4. سرور را اجرا کنید:
   npm start
5. در مرورگر آدرس زیر را باز کنید:
   http://localhost:3000

خروجی:
Hello World!

توضیح:
با اجرای برنامه، سرور Node.js روی پورت 3000 فعال می‌شود.
وقتی مرورگر درخواست مسیر / را ارسال می‌کند، سرور متن Hello World! را به‌عنوان پاسخ برمی‌گرداند.
